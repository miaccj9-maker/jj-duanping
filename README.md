# 晋江段评 (jj-duanping) · SillyTavern 扩展

模仿晋江文学城「段评」功能的酒馆插件：**长按/拖选聊天段落 → 调取 App 让其他角色（或当前角色）评级 → 套 CSS 模板生成段评卡片 → 一键下载卡片图片**。

> 适配 SillyTavern 1.15.x（`generateQuietPrompt` 对象参数版）。

---

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 段落选取 | **电脑端：右键消息文本** → 菜单点「✎ 提取本段写段评」（微信"提取文本"式，自动标蓝整段，可拖动微调），或「✎ 给选中文字写段评」；触屏端：长按消息文本拖选，松手后点浮动「✎ 段评」按钮 |
| 角色评级（多选） | **评价角色可多选**（勾选任意多个角色或"当前角色"），点「⚡ 调取 App 生成段评」后**逐个角色**用其口吻生成段评，全部进入评论列表；生成时自动带上该角色卡片上下文（forceChId） |
| 人设贴合 + 自我意识 | 生成时自动注入该角色的**人设卡**（描述/性格/背景设定 + **口吻参考**：开场白/备选开场/示例对话）+ 自我意识段落：**明确告诉角色这段【原文】（即使来自历史存档片段）正是他与用户共同经历过的真实剧情，他是当事人、不是在追小说**——当前角色与所选角色都按此认知发言，并带**禁止 OOC** 硬约束，评论完全以角色本人身份与口吻输出 |
| 关系感知 | 生成时自动从**当前聊天历史**读取其他出场角色，注入「**剧情在场者**」区块（列出在场角色名，提示按人设中的关系自然带出）——角色评价不是旁观视角，会带入他与用户、与在场其他角色的关系；评价提示词模板已升级 v3（去掉"读者/追小说"视角，明确当事人立场），旧存档提示词自动迁移；角色名识别对酒馆全局变量缺失做了兜底（`name2` 等不存在时自动回退，不再报生成失败） |
| 设置面板 | **内嵌于主面板**（无单独界面）：设置区块直接显示在 CSS 模板下方，**默认展开、无需点击**（书名/章节/水印/字号/行高/字距/提示词/宽度/我的@ID/引擎/入口），滚动即可见；面板头部「设置」按钮一键**滚动定位**到设置区，桌面/手机通用 |
| 角色选择 | 评价角色多选改成**带头像的精致胶囊**：每个角色显示 22px 圆形面具头像（加载失败自动回退首字头像），选中态为主题色描边+淡粉底+加粗，悬停轻阴影，间距统一，整体更高级简洁 |
| 自填 API | 主面板「**使用自填 API 调取模型**」框内**填写 API 地址（含端口）/ Key →「刷新模型列表」→ 选择模型**，带「**测试连接**」一键验证；开启后生成段评走自填 API（OpenAI 兼容 /chat/completions，输出上限 1500 token），不开启则仍走酒馆已连接的 App |
| 角色 @ID | 评论里的 `@ID` **自动读取角色英文名**（纯英文名 / extensions.nickname / alternate_names），可在「角色 @ID 设置」里为每个角色**手动覆盖**，我的 @ID 也可单独设置 |
| 图片宽度 | 预览上方**宽度滑杆**（0 = 跟随模板宽度，10~720px 步进，实时生效），与高级设置数值输入框**双向同步**；修复"改宽变窄"的循环依赖（卡片宽度不再被 iframe 宽度反压）：**设多宽就显示多宽**，宽度缩放仅作用于手机视口 |

| 日间/夜间 | 预览区「**🌙 夜间 / ☀️ 日间**」一键切换，**对所有模板生效**：直接覆盖模板 CSS 变量（`--be-card-fg/bg/sub`）——小票的固定印刷文字（欢迎语、小狗日记标题、日期、正文）夜间自动转亮色；小票标题已改为**真实元素渲染**（不再依赖伪元素，下载图同样可靠显示），夜间纯白；**评论模块同样跟随夜色**（评论在卡片内外的模板都已覆盖：评论背景与卡片同深色、角色评论名亮白、你的评论名亮橙区分、评论文本亮白、头像压暗、回评/点赞图标亮灰），其它模板背景/正文/来源/日期/水印统一高对比暗色；模板 JSON 可选自带 `night` 字段定制专属夜间样式，存档会一并记住日/夜状态 |
| 贴纸 | 预览区「**🧸 贴纸**」：内置 20 个 Emoji + 10 个颜文字 + 图片贴纸（**可上传本地图片**，大图自动压缩至 512px，最多 24 张，本机保存），点击即加到卡片；**微信式拖拽**——在预览里把贴纸任意滑到卡片任意位置（手机触摸同样支持），坐标实时保存；**每张贴纸可用「− / +」调节大小**（emoji/颜文字调字号，图片调宽度，实时收缩放大）；贴纸随卡片缩放/夜间/下载保持完全一致；可在弹窗里删除单张或清除全部，存档会记住贴纸 |
| 手机端适配 | 面板/预览在手机**全屏自适应**：卡片超出屏幕宽度时**等比缩小**完整显示（预览缩放不影响下载图，下载仍为原始分辨率）；手机**长按文本**同样唤醒选段（微信"提取文本"式），长按菜单坐标自动兜底 |
| 性能优化 | 内置模板 JSON（含内嵌图 base64，体积可达 ~900KB）**按 key 缓存解析结果**，预览内容未变不重建 iframe——多次编辑/输入时不再反复解析大模板导致卡顿；生成结果**疑似被截断时自动续写补全一次**（逗号/冒号等半截结尾会再调一次模型接完），仍截断才 toast 提醒 |

| 评论列表 | 所有段评在列表里可**逐条编辑/删除**，实时刷新预览 |
| 平台风评论模块 | 评价**与正文卡片分离**（晋江/Ins 评论渲染进卡片内部、与卡片共用边框圆角阴影，真正一体；其余模板分割线分隔），按模板自动套用对应平台评论样式：晋江段评（默认）、小狗日记小票、Ins名片、X修复版、icity日记；每条评论含**头像、ID、评论文本**（无时间戳），右下角有**回评/点赞**极简矢量图标 |

## 📦 安装

**方式一：直接复制（推荐）**
把 `jj-duanping` 整个文件夹复制到：
```
SillyTavern\public\scripts\extensions\jj-duanping
```
然后刷新酒馆页面（浏览器硬刷新 Ctrl+F5）。

**方式二：压缩包**
解压 `jj-duanping.zip`，同样放到 `public\scripts\extensions\` 下。

启动后控制台出现 `[晋江段评] 已加载` 即成功。

## 🎯 使用方法

**电脑端（推荐：右键唤醒）**
0. 页面右下角常驻绿色 **「✎ 段评」** 按钮——不想右键时，直接点它也能打开面板；
1. **右键**点聊天消息里的文字，弹出菜单：
   - 若已拖选了文字 → 菜单显示「✎ 给选中文字写段评」；
   - 没选 → 菜单显示「✎ 提取本段写段评」——点它后整段文字会被**标蓝高亮**（微信"提取文本"的效果），可继续拖动微调选区；
2. 点高亮文字下方的绿色 **「✎ 段评」** 按钮进入面板；
3. 在面板中：
   - 确认/微调「选中段落」；
   - **勾选**一个或多个「评价角色」（可全选，默认当前角色）；
   - 可填「额外要求」，或在「我的评论」里写一句以自己身份发的评论 →「➕ 确认添加」；
   - 点 **⚡ 调取 App 生成段评**（逐个角色生成，全部进入评论列表）；
4. 评论列表里可**逐条编辑/删除**，右侧预览区实时渲染正文卡片 + 评论模块；
5. 选「CSS 模板」换皮肤（晋江 / X / Ins / icity / 小票各有独立评论样式），或「管理模板」新建/导入；
6. 点 **⬇ 下载图片** 保存 PNG（与预览一致）；点 **📋 复制段评** 复制全部评论文字。

**触屏端**：长按消息文字 → 原生选择手柄出现 → 选中后点浮动「✎ 段评」按钮。

> 也可以直接发 `/duanping 这句台词写得真好` 打开面板并填入该文本。

## 🎨 模板系统

### 卡片 DOM 结构（写 CSS 模板时照此写选择器）

**正文卡片**（评价与正文分离）：

```
.be-card.be-custom
 ├─ .be-head > .be-meta > .be-source
 │     ├─ .be-char-avatar   （原文作者头像，background-image）
 │     ├─ .author           （原文作者名）
 │     ├─ .title            （《书名》）
 │     └─ .chapter          （章节 / 第N条）
 ├─ .be-name                （@原文作者）
 ├─ .be-quote               （选中的原文段落）
 ├─ .be-quote-orig          （出处说明）
 ├─ .be-date                （YYYY-MM-DD）
 ├─ .be-date-cn             （YYYY年M月D日）
 └─ .be-watermark           （水印文字）
```

**评论模块**（`.be-card` 内或之后，与卡片一体、仅一条分割线分隔，无标题文字；无时间戳）：

```
.be-comments                    （顶部 border-top 即分割线，背景与卡片同色）
 └─ .be-comment[data-kind="char"|"user"]
       ├─ .be-comment-avatar   （头像 background-image；无图时 .be-comment-avatar-fallback 首字）
       ├─ .be-comment-name     （评论者名）
       ├─ .be-comment-id       （@ID）
       ├─ .be-comment-text     （评论文本）
       └─ .be-comment-actions  （右下角：回评 / 点赞 极简矢量图标）
```

CSS 变量：卡片根节点提供 `--be-quote-size`、`--be-quote-lh`，模板可直接使用（`font-size: var(--be-quote-size, 15px)`）。

### 模板文件（正文与评论分离，都在 `templates/*.json`）

每套模板是一个独立 JSON 文件，**正文 CSS 与评论 CSS 分开存放**，格式：

```json
{
  "name": "模板名",
  "css": "作用于 .be-card.be-custom 的正文卡片样式",
  "comments": "作用于 .be-comments / .be-comment 的评论模块样式（可选）",
  "commentsInside": false
}
```

- `commentsInside: true` 时评论渲染进**卡片内部**（与卡片共用边框/圆角/阴影，真正一体，如晋江/Ins；此时评论 CSS 里用**负 margin 抵消卡片 padding** 实现通栏贴边，如 `margin: 0 -20px -16px`）；`false`/缺省时评论渲染在卡片下方（分割线分隔）；
- `comments` 缺省时自动套用 `templates/_兜底评论.json` 的通用评论样式；
- **后续添加新模板**：直接把新的 `{"name","css","comments"}` JSON 放进 `templates/` 目录即可，插件启动自动识别，无需改动任何 JS；
- 「管理模板 → 导入 JSON」同样支持该格式（`comments`、`commentsInside` 可选）；「导出」会连 `comments` 一起导出；「建副本」会把该模板的正文 + 评论样式分别拷成自定义模板。

### 管理模板
- 「管理模板」→ 每套模板可**应用 / 建副本（内置）/ 编辑（自定义）/ 导出 / 删除**；
- 「＋ 新建模板」：填名称 + 正文 CSS +（可选）评论 CSS，保存后自动应用并预览；
- 「导入 JSON」：粘贴 `{"name":"…","css":"…"}`（可含 `"comments"`）回车，或把已有的模板 JSON 直接粘进来；
- 「导出」：下载同名 JSON，与内置模板格式完全一致，可互换。

> 内置模板 CSS 从插件 `templates/` 目录读取，不写入设置文件；自定义模板存在 `settings.json` 的 `extension_settings.jj_duanping.customTemplates` 中（同样含 `css` 与 `comments` 两个字段）。

## ⚙️ 高级设置

面板里「高级 ▾」可调：

| 项目 | 说明 |
|---|---|
| 书名 / 章节 | 显示在卡片标题位（留空书名显示《晋江文学城》，章节自动 = 第N条） |
| 水印文字 | 留空 = 无水印 |
| 引用字号 / 行高 | 映射到 `--be-quote-size` / `--be-quote-lh` |
| 评价提示词模板 | 改写评级提示词，`{char}` `{user}` `{quote}` `{extra}` 会被替换 |
| 自填 API | 主面板勾选「使用自填 API 调取模型」→ 填 API 地址（含端口，如 `https://api.openai.com/v1`，Ollama 用 `http://127.0.0.1:11434/v1`）→ 填 Key（可选）→「刷新模型列表」选模型；可先点「**测试连接**」验证地址与 Key；开启后生成走这里 |
| 图片宽度 | 填数字 px 强制卡片宽度，留空 = 跟随模板自带宽度 |
| 我的 @ID / 角色 @ID | 我的 @ID 直接填；「角色 @ID 设置」里逐角色填写（留空自动用英文名） |
| 图片引擎 | 自动 / 强制 html2canvas / SVG 兜底（离线可用） |

## 🖼 图片下载说明

- 默认「自动」：先尝试在卡片预览 iframe 内加载 html2canvas（jsdelivr → unpkg → cdnjs 依次回退），成功后用它截图（对模板里的 `::before/::after` 图标、SVG data-URI 渲染最保真）；
- 网络不可用或加载失败时自动降级到 **SVG foreignObject 引擎**（零依赖），会把伪元素尽量物化为真实节点；
- 头像使用酒馆同源路径，不触发 canvas 跨域污染。

## ❓ 常见问题

- **点「✎ 段评」没反应？** 确认扩展已加载（控制台日志），右键唤醒只对聊天消息的**文字区域**生效（头像/按钮上右键仍是系统菜单）。
- **右键没弹菜单？** 页面装了插件后要硬刷新（Ctrl+F5）；若右键点在头像、空白处，不触发属正常。
- **生成按钮点了没输出？** 需要已连接可用的生成 API（与正常回复同一个 App），报错会以 toast 提示；角色多选时逐个生成，按钮会显示「生成中 i/n」。
- **下载的图片和预览不一样？** 两者渲染的是同一份 iframe DOM；若个别模板的伪元素/网络字体在 html2canvas 下丢失，可切「强制 SVG 兜底」或「建副本」自行调整 CSS。
